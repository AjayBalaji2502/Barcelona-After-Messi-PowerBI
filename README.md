FC Barcelona After Messi- Power BI Performance Analysis:

Project Overview:
This project analyses how FC Barcelona performed after Lionel Messi left the club in 2021, and how the team recovered in the seasons that followed. The aim was to understand how the club's attacking output changed without its all-time top scorer, which players stepped up, and how Barcelona rebuilt over time. The project follows a full data analytics workflow, from data collection and cleaning to dashboard design and written insights.

Data Collection:
--> Player and match data was gathered from several football statistics websites.
--> Data covered recent seasons after Messi's departure, with a focus on player goals and scoring contributions.
--> Data from different sources was combined into one dataset for analysis.

Data Cleaning (Python and Excel):
The raw data was cleaned with Python and then stored and organised in Microsoft Excel.
--> Removed duplicate records.
--> Fixed inconsistent data formats (dates, numbers, names).
--> Standardised column names and structure across sources.
--> Checked for missing or incorrect values.
--> Organised the final dataset in Excel so it was ready for Power BI.

Dashboard Creation (Power BI):
The cleaned dataset was loaded into Power BI to build interactive dashboards.
--> Player goals: Goals scored by each player across recent seasons
--> Top scorers: Highlights the club's leading scorer in each season
--> Key performance metrics: Season-by-season trends in Barcelona's attacking performance
--> Interactive slicers: Filter the dashboard by season to explore the data

Key insights:
A written summary of the analysis explains how Barcelona played after Messi left and how the club recovered;
--> Losing Messi hit goal output hard. Messi scored 30 of Barcelona's 80 league goals in 2020-21. The season after he left, the team fell to 68 goals, and the top scorer was Memphis with just 12.
--> Lewandowski became the new main scorer. After joining in 2022-23, Robert Lewandowski was the club's top scorer for three seasons in a row, with 23, 19 and 27 goals.
--> Barcelona recovered and went past pre-Messi levels. Team goals climbed from 68 (2021-22) to 69, 76, then a peak of 99 in 2024-25, and stayed high at 94 in 2025-26. That season Lamine Yamal led the scoring with 16 goals, which shows a new generation stepping up.
